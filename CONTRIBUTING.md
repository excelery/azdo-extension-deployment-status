# Contributing

## Issues

- **Bugs:** check [SUPPORT.md](SUPPORT.md) first, then open an issue.
- **Feature requests:** open an issue that describes the problem you want solved.

## Pull requests

Please open an issue before starting work, so the change can be agreed first. Pull requests without a
related issue are unlikely to be merged.

## Development

```powershell
npm install
npm test
npm run build
npm run start:dev
```

See [docs/testing.md](docs/testing.md) for testing in Azure DevOps.
